💳 M-Pesa Integration Flow

Payment Process

1. User clicks "Checkout"
   ↓
2. API creates Order (Status: Pending)
   ↓
3. API calls M-Pesa STK Push
   ↓
4. M-Pesa sends push to customer's phone
   ↓
5. Customer enters M-Pesa PIN
   ↓
6. M-Pesa processes payment
   ↓
7. M-Pesa sends callback to API
   ↓
8. API updates Order (Status: Completed)
   ↓
9. Stock automatically reduced

Key Implementation Details

  • OAuth token generation for API access
  • Password encryption (Base64 encoding)
  • Callback endpoint for payment confirmation
  • Automatic stock reduction on success

🎯 Challenges & Solutions

Challenge: Price Changes

Solution: Store price snapshots in cart and order items

Challenge: Stock Overselling

Solution: Validate stock at checkout, reduce only after payment

Challenge: M-Pesa Callbacks

Solution: Public endpoint with request validation and logging

Challenge: Role Management

Solution: User-selectable roles during registration
